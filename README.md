# darkhn

Dark mode version of Hacker News. This is mostly to be able to read Hacker News at night without hurting my eyes. Hackers have to sleep too!

None of the features that you have to be signed-in for work. Instead, clicking on those links takes you to the real Hacker News website. Also, the "Light Hacker News" link in the top right corner takes you to whichever page you're currently on in the real website. There are three pages that are not supported (past, comments, and submit) so instead those take you to the real pages as well.

The domain is meant to be simple, so if you're ever on Hacker News and want to switch to this dark mode, you can replace "news.ycombinator.com" with "darkhn.com" and it will take you to the same page as long as it's not the past, comments, or submit pages.

If for some reason ycombinator doesn't want this page up, they can let me know and I'll take it down.

Enjoy.
